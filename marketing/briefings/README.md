# Daily market briefings

Every morning a research agent writes one file here, `YYYY-MM-DD.md`, on the `marketing-briefings` branch (never on `master`, so nothing on the website changes by itself).

Each briefing has:

1. **Market signals:** the few things that changed in the last 24–72 hours and matter to Vitorra's four businesses (fuel prices and fleet costs, coffee markets and exports, East African freight, first aid and emergency care), each with its source link and date.
2. **What it means for Vitorra:** in business language.
3. **Ready-to-use suggestions:** a Spotlight message (English + Swahili, with dates), a blog topic with an outline, a campaign or WhatsApp idea, and one social post.
4. **Claims check:** anything in the news that we must *not* repeat as our own claim.

Rules the agent follows:
- Only real, dated, linked sources. If a figure can't be sourced, it isn't used.
- Never claim anything Vitorra does not do or is not authorised to say (for example, no Ugandan regulatory approvals that don't exist, no savings guarantees, no SEAL medical claims beyond its US FDA 510(k) clearance).
- Suggestions are drafts. People decide what goes live.
